Adopt the kit with an AI coding agent

Most teams meet this kit through a coding agent. Told only to "use the Novus kit", an agent guesses, and a portal ends up with its own side navigation, its own filter bar and its own idea of what blue means. This page gives the agent the same rules the kit enforces on itself, and gives you prompts to copy.

Rules are context, not enforcement. An agent can still get it wrong, so the last step of every prompt is a check you can read. The kit's own release gates remain the thing that actually blocks a mistake.

1. Give your agent the rules once

The package ships an instruction file for each agent, in the format that agent reads. Copy the one you use into your repository and your agent follows these rules in every session, without anyone restating them. Upgrading the package brings the updated rules with it.

The files are generated from one source in the kit, so they cannot disagree with each other or with this page. Do not hand edit them: upgrade the package instead, and keep your own project rules in a separate file.

2. Work in this order

  1. Install and wire in. The package installs from public npm with no registry setup and no token. The theme script belongs in the document head so the theme applies before first paint.
  2. Convert one screen, not all of them. A single converted screen shows you what the agent understood, while a whole application converted at once is unreviewable.
  3. Read what came back. Check the screen at 1440px and at 375px, and with JavaScript off if the screen is meant to work without it.
  4. Then widen. Once one screen is right, the same prompt scales to the rest, and the instruction file keeps later sessions consistent.

3. Prompts to copy

Each prompt names the real files this release ships, so the agent has no reason to invent a path. Paste one as it is.

If the result looks wrong

  • Hardcoded values crept in. Ask for a diff of every colour and size the agent introduced, then ask which token covers each one.
  • New markup instead of kit components. Point the agent at the component catalog and ask it to name the component it replaced.
  • Short content wrapping to two rows. That is the defect this kit was corrected twice to prevent. Ask for the audit prompt above, at both widths.
  • Console screens missing the shell. The Admin Kit is the reference: four flavors, all generated from one pattern layer.
