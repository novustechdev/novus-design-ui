Foundations

Design principles

The Novus visual system reads as a calm 24/7 operations floor, mastery without drama. Essence: Trusted · Precise · Inclusive · Enduring.

Tokens first

Every colour, size, space, radius, and shadow references a token. If you're about to type a hex value or a pixel size the tokens define, use the variable instead.

One accent per view

Novus Blue is the default accent. Green is success and status only, never a page or panel ground. A product theme swaps the accent, never adds a second one.

Hover means clickable

There is exactly one hover treatment, lift, raised shadow, accent border, and it is reserved for elements that do something on click. Static tiles never react.

Mobile first

Base styles target the phone and scale up with min-width queries. 375px is the test baseline; touch targets are at least 44px; nothing depends on hover or JavaScript where a native mechanism exists.

Data is the design

Information-dense, near-flat surfaces: 1px borders, subtle shadows, no gradients, no decoration. Emphasis by weight, never italics or all-caps.

Dark is re-tuned, not inverted

Light is home. Dark mode re-dresses the same roles for app screens, raised surfaces get lighter, text roles swap to their dark steps, and logos swap to white.

The model

Novus delivers digital transformation as Service as Software: we provide the technology and run 24/7 managed operations. The positioning line:

"We carry the infrastructure, technology and operations, so our partners can carry the market and care for their end customers."
