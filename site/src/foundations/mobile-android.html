Android foundations

The Novus design system mapped onto native Android: Jetpack Compose with Material 3, the platform's standard stack. Every value below is taken from tokens.css (rem converts at 16px per rem to dp), so web and mobile share one source of truth; the build rejects any colour on this page that is not a token value.

Design mapping, not a run-verified guide: this page maps tokens to Material 3 roles and names its targets (Compose BOM 2026.x, Material 3 1.5.x, Kotlin 2.x). The framework guides' build-and-run verification does not apply here; values are machine-checked against tokens.css instead.

Color scheme

Material 3 wants roles, not raw colours. The mapping keeps the kit's rules: white ground, one accent (Novus Blue), status colour only on judgements.

import androidx.compose.material3.darkColorScheme
import androidx.compose.material3.lightColorScheme
import androidx.compose.ui.graphics.Color

val NovusLight = lightColorScheme(
    primary            = Color(0xFF0070C0), // --accent (blue-500)
    onPrimary          = Color(0xFFFFFFFF), // --text-on-accent
    primaryContainer   = Color(0xFFEAF3FB), // --accent-subtle (blue-50)
    onPrimaryContainer = Color(0xFF00457A), // --accent-text (blue-700)
    secondary          = Color(0xFF51606F), // --neutral-600 (text-secondary)
    background         = Color(0xFFFFFFFF), // --bg (white ground, always)
    onBackground       = Color(0xFF0E2336), // --text (neutral-900)
    surface            = Color(0xFFFFFFFF), // --surface
    onSurface          = Color(0xFF0E2336),
    surfaceVariant     = Color(0xFFF4F7FA), // --bg-subtle (neutral-50)
    onSurfaceVariant   = Color(0xFF51606F),
    outline            = Color(0xFFDCE3EB), // --border (neutral-200)
    error              = Color(0xFFC0473F), // --danger (red-400)
    onError            = Color(0xFFFFFFFF),
    errorContainer     = Color(0xFFFBEAE9), // --danger-subtle (red-50)
    onErrorContainer   = Color(0xFF8A2823), // --danger-text (red-600)
)

val NovusDark = darkColorScheme(
    primary            = Color(0xFF0070C0), // accent holds in dark; white text stays AA
    onPrimary          = Color(0xFFFFFFFF),
    primaryContainer   = Color(0xFF073355), // blue-800
    onPrimaryContainer = Color(0xFFA6CCEC), // blue-200 (the dark-lockup blue)
    secondary          = Color(0xFFAEBCC9), // dark --text-secondary
    background         = Color(0xFF0B1620), // dark --bg (neutral-950)
    onBackground       = Color(0xFFE7EDF3), // dark --text
    surface            = Color(0xFF122131), // dark --surface
    onSurface          = Color(0xFFE7EDF3),
    surfaceVariant     = Color(0xFF18293B), // dark --surface-raised
    onSurfaceVariant   = Color(0xFFAEBCC9),
    outline            = Color(0xFF2A3B4D), // dark --border
    error              = Color(0xFFD56A61), // dark --danger (red-300)
    onError            = Color(0xFF0B1620),
    errorContainer     = Color(0xFF6E201C), // red-700
    onErrorContainer   = Color(0xFFF0A39C), // dark --danger-text
)
  • Success and warning are judgement colours, never decoration: light 0xFF00A04A / 0xFFE8A300, dark 0xFF2BB266 / 0xFFE8A300 (the token values). Define them as semantic extension colours, not Material roles, so they only appear where a judgement exists.
  • Do not enable dynamic colour (Material You): the brand palette is the palette.

Typography: Carlito only

Bundle Carlito (400 and 700) as font resources. The TTF comes from the design system master or Google Fonts (Carlito is an open font there); this npm package ships woff2 for the web only.

val Carlito = FontFamily(
    Font(R.font.carlito_regular, FontWeight.Normal),
    Font(R.font.carlito_bold, FontWeight.Bold),
)

// The kit type scale, rem times 16 = sp
val NovusTypography = Typography(
    displaySmall  = TextStyle(Carlito, fontSize = 30.sp, lineHeight = 36.sp), // --text-2xl
    headlineSmall = TextStyle(Carlito, fontSize = 24.sp, lineHeight = 32.sp), // --text-xl
    titleLarge    = TextStyle(Carlito, fontSize = 20.sp, lineHeight = 28.sp, fontWeight = FontWeight.Bold), // --text-lg
    titleMedium   = TextStyle(Carlito, fontSize = 18.sp, lineHeight = 28.sp, fontWeight = FontWeight.Bold), // --text-md
    bodyLarge     = TextStyle(Carlito, fontSize = 16.sp, lineHeight = 24.sp), // --text-base
    bodyMedium    = TextStyle(Carlito, fontSize = 14.sp, lineHeight = 20.sp), // --text-sm
    labelSmall    = TextStyle(Carlito, fontSize = 12.sp, lineHeight = 16.sp), // --text-xs
)
  • Two weights only, regular and bold, exactly like the web kit.
  • Sizes are sp so platform font scaling keeps working; never disable it.

Shape and spacing

val NovusShapes = Shapes(
    extraSmall = RoundedCornerShape(6.dp),   // --radius-sm
    small      = RoundedCornerShape(6.dp),
    medium     = RoundedCornerShape(8.dp),   // --radius-md
    large      = RoundedCornerShape(12.dp),  // --radius-lg
    extraLarge = RoundedCornerShape(16.dp),  // --radius-xl
)

object NovusSpace { // --space-1 .. --space-8, rem times 16 = dp
    val s1 = 4.dp;  val s2 = 8.dp;  val s3 = 12.dp; val s4 = 16.dp
    val s5 = 24.dp; val s6 = 32.dp; val s7 = 48.dp; val s8 = 64.dp
}

Dark mode: dual trigger, same as the web

Follow the system AND offer a persisted in-app override, the mobile analog of the kit's dual-trigger rule.

enum class ThemePref { System, Light, Dark } // persist with DataStore

@Composable
fun NovusTheme(pref: ThemePref, content: @Composable () -> Unit) {
    val dark = when (pref) {
        ThemePref.System -> isSystemInDarkTheme()
        ThemePref.Light  -> false
        ThemePref.Dark   -> true
    }
    MaterialTheme(
        colorScheme = if (dark) NovusDark else NovusLight,
        typography  = NovusTypography,
        shapes      = NovusShapes,
        content     = content,
    )
}

Rules that carry over unchanged

  • White (or near-black) ground, no gradients, elevation as outline over shadow.
  • One accent per view; success and warning only where a judgement exists; risk messages always red; amounts always neutral.
  • Product names lowercase and solid-set (novapay); logos are placed assets from logos/, never redrawn or typed.
  • Touch targets 44dp minimum; test at small-phone width first.
