Icons

One line icon style for every Novus console: a 24-unit square grid, a 2-unit stroke with round caps and joins, no fill, drawn in the current text colour. The set is drawn in-house and ships as inline markup from admin-kits/shared/icons.mjs, so there is no icon font and no third-party request.

Rules

  • Draw on the 24-unit grid with a 2-unit stroke, round caps and joins, and no fill. Colour comes from currentColor, so icons follow text, accent, and dark mode on their own.
  • Use 16px (.icon--sm) beside small text, 20px (.icon) in navigation and buttons, and 24px (.icon--lg) standalone.
  • An icon supports a label; it rarely replaces one. Icon-only controls carry an accessible name and a 44px target.
  • Decorative icons carry aria-hidden="true"; the markup below already does.
  • One style per view: never mix these with filled, duotone, or third-party icons, and never use an icon font.
  • Product and platform identity uses the official pictographs from Logos, not this set.
