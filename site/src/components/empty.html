Usage

  • Plain text plus one action button: no illustration, no emoji, no decoration. The empty state is information, not a mascot moment.
  • First line says what is empty; second line says when content will appear or what to do; the button does it.
  • A filter-produced empty state offers to clear the filter (secondary); a first-run empty state offers the creating action (primary, if it is the view's one primary).
  • Never show an empty state while loading; that is the skeleton's job.
