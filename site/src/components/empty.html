Usage

  • .empty composes .card: bordered surface, centred, and min-height:14rem so the block holds the space the rows would have filled instead of collapsing the page.
  • Plain text plus one action. No illustration, no emoji, no decoration — the empty state is information, not a mascot moment.
  • First line says what is empty; second line says when content will appear or what to do; the button does it. Keep the second line to two lines at most — .empty__text caps its measure at 34ch.
  • A filter-produced empty offers to clear the filter (secondary); a first-run empty offers the creating action (primary, if it is the view's one primary). When there is no action to offer, drop .empty__action entirely rather than inventing one.
  • Never show an empty state while loading; that is the skeleton's job. Never an empty state on an error — that is an alert.
