Usage

  • Put every data table in a .tablewrap: cells stay on one line and the table scrolls sideways inside its container instead of squeezing columns, so identifiers, names, chips, dates, and amounts never break across lines. The page itself never scrolls sideways.
  • Free-text columns opt back into wrapping with .cell--wrap, which keeps a readable minimum width.
  • A second fact in a cell goes in a .cell-stack: two single-line lines, the second one muted.
  • Numeric columns take class="num" on the header and the cells (right-aligned, tabular numerals); row actions take .cell--actions, aligned to the end.
  • Header cells sit on the subtle tint; rows highlight on hover for scanning. See Alignment and content fit.

Popovers and menus in a table

The scroll wrap is a containing block, so anything absolutely positioned inside it is clipped by it. That is deliberate: it keeps visually hidden text from extending the page sideways on a phone. It also means a row menu, popover or tooltip must render outside the wrap rather than inside the cell it belongs to.
