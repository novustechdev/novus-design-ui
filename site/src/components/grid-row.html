Usage

  • The grid wraps items into new rows on its own: more items than columns simply continue on the next row, and narrower screens get fewer columns.
  • Mobile-first: use auto-fit/minmax() columns so layouts stack on phones instead of squeezing.
  • .row is a wrapping flex line for buttons, badges, and chips: when space runs out it flows onto the next row (the demo is width-constrained so you can see it happen).
  • Gaps come from the spacing scale (--space-*), never ad-hoc pixel values.
