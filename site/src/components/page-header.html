Usage

  • Every console screen opens with a page header: the breadcrumb (area, then screen), the title, and the screen's actions aligned to the end of the title row.
  • Actions stay in one row. On narrow screens the whole group moves under the title; buttons never wrap one by one.
  • At most one primary action; the rest are secondary or ghost.
  • The description is one sentence about what the screen holds.
  • A detail screen opens with Back in place of the breadcrumb: a ghost button with the arrow icon and the word Back, never an arrow alone and never a text link. It is the only thing above the title.
  • Back returns to the screen the person came from, the list with its filters, the dashboard, a search, so they land where they left. Mark it data-back and the console script calls the browser's own back.
  • Its href is the parent screen. That is where Back goes when there is nowhere to return to: a bookmark, a shared link, an email, or JavaScript off. Back never leaves the console.
  • The label stays Back, not Back to Transactions, because the destination depends on where the person entered from.
