Usage

  • An ordered list in a labelled nav; the current page is plain text with aria-current="page", never a link.
  • The slash separator is drawn by the console layer between items, muted, so assistive technology reads only the trail.
  • Items never wrap mid-label; long trails wrap between items. Three levels is the comfortable maximum.
  • On console screens the breadcrumb sits above the title in the page header; it states location and never replaces the navigation.
