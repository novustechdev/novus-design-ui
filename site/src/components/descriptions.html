Usage

  • A native <dl> on a two-column grid: muted terms left, values right. This is the record-detail pattern for drawers, sheets, and detail pages.
  • Values stay neutral; a judgement renders as a self-describing chip, never as coloured text.
  • Order fields by operational priority, not alphabetically; the field someone came to check goes first.
  • On narrow screens the grid collapses naturally; never truncate values with ellipsis in audit views.
