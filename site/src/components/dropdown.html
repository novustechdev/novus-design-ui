Usage

  • For choosing one value, use the native <select class="select"> inside a .selectwrap: the wrapper draws the chevron inset from the edge and the platform provides the option list, keyboard support, and mobile pickers.
  • For an action menu, use native <details> with a button-styled <summary> and a .card panel: it opens on click, closes on a second click, and needs no JavaScript.
  • Menus are click-driven, never hover: touch devices and keyboard users depend on it.
  • Keep menu items short, verb-first, and never more than seven; longer lists belong in a select.
