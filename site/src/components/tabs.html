Usage

  • Tabs are native radio inputs switched by CSS :has(): no JavaScript, arrow keys move between them, and where :has is unsupported every panel shows at once rather than vanishing.
  • Each .tabs__tab label wraps its own radio input, so there are no ids to keep in sync; :has(input:checked) drives the colour and each .tabs__panel matches its tab by order.
  • Colour carries three states: idle is --text-secondary, hover lifts to --text on --bg-subtle, and the selected tab fills --accent with --text-on-accent. Hover on the selected tab deepens to --accent-hover so it still reads as one.
  • The radio is visually hidden but keeps its focus ring, drawn on the label with focus-visible. Never display:none the input or keyboard users lose the tab bar.
  • Tabs divide one subject into facets. For moving between subjects use navigation; for a linear flow use the stepper.
  • Keep labels to one or two words; the CSS matches up to six.
