Usage

  • Configuration is a settings layout, never a grid of cards: a section menu beside grouped sections, each section a list of rows.
  • One row, one setting: the label says what it is, the description says what it affects, and a single control sits at the end of the row. On phones the control moves under its description.
  • The menu is plain anchors and every section stays on the page, so the screen works with JavaScript off and deep links survive.
  • Group by subject (profile, appearance, notifications, security, access), not by control type. Five to seven rows per section reads well; beyond that, split the section.
  • Destructive actions sit in their own row with a plain description of what they end, and use the danger button only when the action is irreversible.
