Usage

  • Page buttons are ghost buttons; the current page carries the accent border and aria-current="page": the one accent in the control.
  • For dense tables prefer the compact form (count plus Previous/Next), the same pattern the Admin Kit data grid uses.
  • State the total ("Page 2 of 12") so users know the size of what they are paging through.
  • Ten rows per page is the kit default for data tables.
