Usage

  • Skeletons are static grey blocks from the neutral tokens: no shimmer, no pulse. Decorative animation is banned; a calm placeholder is the Novus loading state.
  • Match the skeleton's shape to the content that will replace it (rows for a table, a card for a card), so nothing jumps on arrival.
  • Show a skeleton only for loads long enough to notice; flashing one for a fast response is worse than nothing.
  • Mark the loading region with aria-busy="true" until the real content lands.
