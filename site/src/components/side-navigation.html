Screen content. The menu button collapses the navigation at desktop width; on a phone it opens the navigation as a drawer.

Usage

  • Top-level links for the one or two screens people use most; everything else sits in groups named for an area, set in small caps with one line icon and a chevron.
  • The group holding the current page is open. The current link carries the accent tint, the accent edge, and aria-current="page".
  • One visually hidden checkbox drives the menu button: at desktop width it collapses the navigation, and below 900px it opens the navigation as a drawer with a scrim that closes it. No JavaScript is required; the console script only closes the drawer after a link is followed and on Escape.
  • Labels are one to three words and never wrap. Rows are 36px on fine pointers and 44px on touch screens.
