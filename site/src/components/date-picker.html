Usage

  • The date picker is the platform's own: <input type="date" class="input">. The browser supplies the calendar popup, locale formatting, keyboard entry, and mobile wheels; the kit supplies the field styling.
  • Never re-implement a calendar popup in JavaScript: the native control is more accessible and better localized than any custom widget.
  • For ranges, pair two date fields on one .row and validate that the end is not before the start.
  • Constrain input with min/max attributes instead of error messages when the valid window is known.
