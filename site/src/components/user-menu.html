Usage

  • The trigger is a person icon, the user's handle, and a chevron. The handle truncates; below 520px only the icon shows and the name stays available to assistive technology.
  • The panel lists identity first, then preferences as label and control rows (on consoles the theme toggle lives here), then Sign out alone at the ruled foot.
  • Native details opens and closes with JavaScript off; the console layer's script adds Escape and outside-click dismissal for any details[data-dismiss].
  • Sign out goes to the signed-out page.
