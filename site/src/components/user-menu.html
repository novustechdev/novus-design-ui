Usage

  • The trigger is a person icon, the user's handle, and a chevron. The handle truncates; below 520px only the icon shows and the name stays available to assistive technology.
  • The panel lists identity first, then Profile as the one destination it offers, then preferences as label and control rows (on consoles the theme toggle lives here), then Sign out alone at the ruled foot. Profile and Sign out both carry a label and an icon, so neither is a row of unlabelled glyphs.
  • Profile lives in the account menu, not the side navigation. The header already carries the person's identity, and a side navigation entry for their own profile would push the console's actual destinations around.
  • Profile goes to the person's own settings, the Profile section of the settings page.
  • Native details opens and closes with JavaScript off; the console layer's script adds Escape and outside-click dismissal for any details[data-dismiss].
  • Sign out goes to the signed-out page.
