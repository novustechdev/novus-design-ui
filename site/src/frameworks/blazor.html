Novus Design for Blazor

The kit is plain CSS + static assets, so Blazor (Server and WebAssembly) consumes it with no wrapper library: serve the package from wwwroot, link one stylesheet, and use the component classes in your Razor markup.

1. Get the package into wwwroot

Install with npm as usual, then copy the package into wwwroot/lib at build time with an MSBuild target in your .csproj:

<Target Name="CopyNovusKit" BeforeTargets="Build">
  <ItemGroup>
    <NovusKit Include="node_modules/@novus/design-kit/**/*" />
  </ItemGroup>
  <Copy SourceFiles="@(NovusKit)"
        DestinationFiles="@(NovusKit->'wwwroot/lib/novus-design-kit/%(RecursiveDir)%(Filename)%(Extension)')"
        SkipUnchangedFiles="true" />
</Target>

2. Link it once

In Components/App.razor (.NET 8+) or wwwroot/index.html (WebAssembly), inside <head>:

<link rel="stylesheet" href="lib/novus-design-kit/tokens.css" />
<script src="lib/novus-design-kit/js/novus-theme.js"></script>

3. Use the classes in Razor markup

<button class="btn btn--primary" @onclick="Submit">Talk to us</button>

<div class="card card--interactive" style="position:relative">
    <h3>@Title</h3>
    <p class="muted">@Summary</p>
    <button class="card-trigger" aria-label="Open" @onclick="Open"></button>
</div>

4. Theme toggle via JS interop

@inject IJSRuntime JS

<button class="btn btn--ghost btn--sm" @onclick="Toggle">Theme</button>

@code {
    private async Task Toggle() =>
        await JS.InvokeVoidAsync("novusTheme.toggle");
}

Verified result

Rendered from this guide's own sample project, executed and verified on 2026-08-26 against the .NET SDK 10.0 Blazor Web App template.

Rules of the road

  • The default Blazor template ships Bootstrap and an app.css, and Bootstrap's .btn collides with the kit's. Remove those two stylesheet links from App.razor: the kit replaces them.
  • The kit's classes are global by design, they compose with Blazor CSS isolation; you never need ::deep to reach them.
  • Don't re-declare brand values in component-scoped CSS; reference var(--…) tokens there too.
  • Keep the theme script in <head> so the persisted choice applies before first render.
  • Pairing with Fluent UI Blazor? See Novus Design with Fluent 2, Novus tokens stay the source of truth.
