Novus Design System

Build on the Novus design system

One package carries the whole visual system: design tokens, component styles, the Carlito typeface, dark mode, and the official brand assets. Install it, import one stylesheet, and every screen you build is on-brand by construction.

Install the kit Browse components
npm install novus-design-kit tokenless, no registry setup

Designed for the operations floor

Trusted, precise, inclusive, enduring: a calm visual language for enterprise products, delivered as Service as Software across banking, payments, and retail.

Enterprise visual language

Monochrome near-flat surfaces, one accent per view, data-dense layouts, AA contrast in both themes. The product's data is the design: no gradients, no decoration.

Token-first components

22 component families from one stylesheet, every value a token. Dark mode is dual-triggered and built in; the persisted toggle ships with the package.

Verified, not promised

Every framework and theme guide is executed in a real project before it ships, with the rendered result on its page. Unverified guides are excluded by the build itself.
