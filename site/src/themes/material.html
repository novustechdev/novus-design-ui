Themes

Novus Design with Material

Teams using Material UI (MUI) keep its component behaviour and re-skin it with Novus tokens. MUI only computes colour variants when you omit them — so provide every variant explicitly as a var(--…) reference and the strings pass straight through to CSS, staying in sync with dark mode.

1. Load the kit alongside MUI

import "@novus/design-kit/js/novus-theme.js";
import "@novus/design-kit/tokens.css";

2. Derive the MUI theme from Novus tokens

import { createTheme, ThemeProvider } from "@mui/material/styles";

const novusMui = createTheme({
  typography: { fontFamily: "var(--font-sans)" },
  shape: { borderRadius: "var(--radius-md)" },
  palette: {
    // all variants given -> MUI computes nothing, strings pass through
    primary: {
      main: "var(--accent)",
      light: "var(--accent-hover)",
      dark: "var(--accent-active)",
      contrastText: "var(--text-on-accent)",
    },
    error: {
      main: "var(--danger)",
      light: "var(--danger-subtle)",
      dark: "var(--danger-text)",
      contrastText: "var(--text-on-accent)",
    },
    background: { default: "var(--bg)", paper: "var(--surface)" },
    text: { primary: "var(--text)", secondary: "var(--text-secondary)" },
    divider: "var(--border)",
  },
});

<ThemeProvider theme={novusMui}>
  <App />
</ThemeProvider>

3. Dark mode

Because every mapped value is a variable, the palette re-tunes when novusTheme.toggle() flips data-theme — no second MUI theme needed. Don't use MUI's palette.mode: "dark" switching for brand surfaces; the tokens already carry both modes.

Rules of the road

  • MUI supplies behaviour (data grid, autocomplete, dialogs); Novus supplies identity. Never run two accent systems on one view.
  • Always give main, light, dark, and contrastText together — an omitted variant makes MUI try to compute from a var() string, which fails.
  • In sx props and styled components, keep referencing var(--…) tokens directly.
  • Where a MUI component and a kit component overlap (buttons, chips, cards), prefer the kit's class-based component on brand-critical surfaces.
  • Logos remain placed assets from the package — theming never touches them.
