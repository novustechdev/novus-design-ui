# Implementation Plan: Novus Design Kit — Component Library & Reference Site

**Branch**: `001-novus-design-kit` | **Date**: 2026-08-26 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/001-novus-design-kit/spec.md`

## Summary

Package the existing Novus Design System Kit v2 (tokens.css, Carlito fonts, logos,
photos) as an installable npm package on a private Novus registry, add a tiny
pre-paint theme helper, and build a public ant.design-style reference site
(design-system foundations + component overview + per-component detail pages)
generated by a zero-dependency Node build script from a component manifest. The
site is built with the kit itself. Constitution quality gates are automated as a
release-blocking script.

## Technical Context

**Language/Version**: CSS (custom properties) + HTML; Node.js ≥ 20 for the site
build script and gate tooling only (no runtime dependency)

**Primary Dependencies**: None at runtime. The package ships static files
(tokens.css verbatim, woff2 fonts, PNG/JPG assets, one small JS theme helper).
Site build: zero-dependency Node script (`site/build.mjs`)

**Storage**: N/A (static files; component manifest is a JSON file)

**Testing**: `scripts/gates.sh` — automated constitution gate audits (token/hex
audit, gradient grep, radius audit, SaaS-string grep, CJK leak grep, manifest↔
page completeness); manual release checks per quickstart.md (dark parity with
toggle + OS + JS off, 375px pass, hover audit)

**Target Platform**: Evergreen browsers (last 2 major versions); reference site
is a static site deployed to GitHub Pages (clarified decision; workflow in
.github/workflows/pages.yml runs the gates before deploying)

**Project Type**: Library (npm package) + static documentation site

**Performance Goals**: Reference site pages render as static HTML with one
stylesheet — first page usable without JS; component snippet copy-paste works
verbatim (SC-005)

**Constraints**: `tokens.css` self-hosts Carlito via relative `fonts/…woff2`
paths → fonts MUST sit beside tokens.css in the published package. Package is
private (proprietary photos/logos); site is public. All styling derives from
tokens — no ad-hoc values. Dark mode dual-trigger with pre-paint persisted
toggle. Deck/poster classes (`.novus-slides`, `.nslide*`, `.novus-poster`) are
out of catalog scope for v1 (decks have their own template docs)

**Scale/Scope**: ~20 component families (from the 90 classes in tokens.css),
7 foundation pages, 1 overview page, ~20 detail pages, ~7 MB of brand assets

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

| Gate | Principle | Verdict |
|------|-----------|---------|
| G1 Token-first | I | **PASS** — tokens.css ships verbatim as the package core; site styles reference `var(--*)` only; gates script greps for ad-hoc hex/px |
| G2 Enterprise monochrome | II | **PASS** — white grounds, no gradients, borders over shadows, one accent. Radius rule (constitution v1.0.1): only values from the tokens.css radius scale, no ad-hoc radii — tokens and principle now agree |
| G3 Component reuse | III | **PASS** — the site is built exclusively from shipped component classes; no new components invented; every component gets a demo page (enforced by manifest completeness gate) |
| G4 Accessibility & responsive | IV | **PASS** — dual-trigger dark mode + pre-paint toggle shipped as the package's JS helper; 375px/44px/contrast/JS-off checks in gates + quickstart |
| G5 Brand & copy fidelity | V | **PASS** — logos/photos ship as placed assets; site copy sourced from `Novus_Context.md`; SaaS-string grep is a blocking gate; lowercase product names |

Post-Phase-1 re-check: design artifacts introduce no new violations — the only
addition beyond packaging is `js/novus-theme.js` (required by Principle IV's
pre-paint toggle rule) and the zero-dependency site generator (tooling, not a
shipped component). **PASS.**

```text

tokens.css               # verbatim copy of references/Novus_Design_System_Kit_v2/tokens.css
fonts/                   # carlito *.woff2 (woff2 only; ttf not shipped)
logos/                   # official logo/lockup/icon assets (as in the reference kit)
photos/                  # approved photography
js/
└── novus-theme.js       # pre-paint persisted dark-mode toggle helper (~20 lines)
README.md                # install + wiring instructions (mirrors site quick start)
CHANGELOG.md             # semver change log, breaking changes flagged

site/
├── build.mjs            # zero-dependency static site generator
├── components.json      # component manifest: id, name, category, variants, page fragment
├── src/
│   ├── partials/        # shared shell: header (master lockup), nav, footer
│   ├── foundations/     # principles, color, typography, layout, logos, photography, dark-mode
│   └── components/      # one fragment per component family (examples + snippets + guidance)
└── dist/                # generated public site (deploy artifact, gitignored)

scripts/
└── gates.sh             # constitution quality-gate audits (release blocking)

references/              # upstream kit snapshot — read-only source of truth, never edited
```

**Structure Decision**: The repository root *is* the npm package (single
project). `tokens.css` + `fonts/` keep their relative layout because the
stylesheet's `@font-face` uses relative paths. The docs site lives in `site/`,
consumes the same root files the package publishes (proving FR-014), and is
excluded from the npm tarball via the `files` allowlist.
